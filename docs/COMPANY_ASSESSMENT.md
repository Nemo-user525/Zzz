# 公司检索与四维评估

在现有第二个工作区「公司检索与四维评估」中搜索关键词，选择候选主体后生成评估。公开公告及历史回放按需展开，不另开评估页面。

## 交互与信息来源

支持企业名称片段、证券代码、巨潮目录拼音和已入库行业关键词；空格分开的多个词采用同时匹配。关键词只负责筛选候选，不能自动证明工商身份。未覆盖的非上市企业可建立待核实主体并补充资料，不会伪造检索结果。

点击候选企业的「评估」后，按证券代码读取已接入的东方财富公开财报。现金趋势来自实际报告期货币资金；资产负债率来自同一期资产负债表。企查查只有在接口可用并确认主体后才进入评估；无密钥、空记录和未返回字段保持未知。手工补充在浏览器会话内处理，不上传、不持久保存；切换主体清空。

界面采用深色分析台、现金趋势、四维核对关系图和项目状态卡。关系图连接表示“维度—核对项”，不是股权关系或神经网络推理轨迹。图中数量是有数据或补充线索的项目数，不是风险分数。灰色为资料不足。

## 规则版本：访谈参考 v1

所有比例来自用户提供的杭州银行访谈反馈，尚未验证为银行统一授信要求。不输出自动审批、违约概率或证券买卖判断。

| 维度 | 项目与判定 |
| --- | --- |
| 现金与负债 | 可自由使用现金 ÷ 月均完整刚性支出；小于 3 个月关注，3–6 个月为访谈区间，6 个月及以上说明覆盖时长；财报货币资金不自动等于自由现金。约 40% 为负债率参考，超出需结合行业核对。 |
| 信用与治理 | 处罚/异常、执行/失信、纳税信用、抵押/股权出质、频繁股权变更、大量质押。接口记录为待核验线索；手工“未见”与接口记录冲突时仍提示核对。A/B 为访谈参考，M 不当作失信。 |
| 客户与人员依赖 | 前两大客户收入占比；无自定参考上限时仅展示，不擅设阈值。分别核对客户资源、核心技术是否依赖单一员工。 |
| 口碑 | 员工认可度 ≥80%、离职率 ≤15%、无工资/社保欠付、供应商最长逾期 ≤30 天、售后投诉率 ≤10%；产品认可度保留实测占比，不擅设参考线。 |

补充数据必须同时填写来源说明与统计期间/样本口径才参与判定；所有补充仍标为未独立核验。未知不当作零；比例限制在有效范围，离职率、认可度与投诉率口径在表单提示。全部零支出时不计算无限覆盖。

企业、投资者、小白、老年人共享同一组事实与参考线，只调整关注顺序、文字和下一步动作。大字模式增强文字可读性。当前资料与历史回放严格分开；过旧财报提示补充较新资料。

核心实现：`frontend/src/assessment.ts`（确定性规则）、`AssessmentDashboard.tsx`（交互与图表）、`backend/app/services/company_keywords.py`（关键词匹配）。规则不依赖语言模型编造数值。

核验依据：[国家税务总局纳税缴费信用管理办法](https://fgk.chinatax.gov.cn/zcfgk/c100012/c5240851/content.html)。
