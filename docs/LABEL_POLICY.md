# 历史结果标签规则 labels-1

没有统一“暴雷=true”。事件阶段、受影响法律主体、公开确认日期、发生日期和证据分别保存。当前已实现并实际支持的类型：

| 类型 | 阶段 | 作为结果标签 |
|---|---|---|
| delisting_notice | 拟终止上市事先告知 | 否 |
| delisting_decided | 终止上市决定已收到 | 是 |
| regulatory_penalty | 行政处罚决定已收到 | 当前作为独立事件，不自动等同债务违约 |
| restructuring_plan_approved | 法院裁定批准重整计划 | 是，与受理申请不同 |
| restructuring_completed | 裁定确认重整计划执行完毕 | 是，是进展结果，不是新增违约 |
| subsidiary_management_notice | 子公司管理股指定预告 | 否，主体是 Zinitix，不能迁移为母公司退市 |

当前正向记录 6 条/5 家企业，其中康美有重整批准、执行完毕两个不同阶段。不能把它们当 6 家失败企业，也不能统称 6 次供应商货款违约。

尚无经核验样本和标签规则的类型：债券到期未偿付、贸易款逾期、破产申请/法院受理、停产、ST/*ST、失信执行等。新增时必须明确债务对象、法律主体、阶段、发生/披露时间及原始证据；词语命中或模型推断不能授予标签。

查询窗口可指定 1–730 天，UI 默认 180 天；结果按该窗口内的公开可用时间查询，实际发生日另列。

| 状态 | 本轮行为 |
|---|---|
| observed_positive | 有合格原始文档支持明确阶段；一家公司可有多种结果 |
| no_event_observed_within_coverage | 预留，当前 0；须先完成声明范围内同强度检索及最后成功观察记录 |
| right_censored | 没有已确认结果且窗口尚未结束，动态查询返回 |
| insufficient_coverage | 没有结果但覆盖不足，不能当负样本 |

“可能”“尚未”“不予受理”“已经偿付”、条件句不能支持已发生违约；诉讼≠败诉，被执行≠失信，破产申请≠受理，退市≠拖欠供货款。标签撤回或证据降级后，历史结果查询不再返回该记录。没有证实跨网站最早公开时刻，确认时间只称“本库原文公开确认日”。
