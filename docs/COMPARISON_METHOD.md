# 对照方法 cashflow-industry-size-1

预设信号：当时已公开、同报告期的经营活动现金流为负。规模使用同一快照里的总资产。确定性规则顺序如下：

1. 在同一 as_of 查询每家企业，缺少时点入池文档则排除。
2. 研究行业分类相同；该分类用于抽样，尚非权威行业编码。
3. 两家均有原文支持的总资产和经营现金流，资产为正，规模相差不超过两倍（`abs(log2(candidate/target)) <= 1`）。
4. 经营现金流均为负，报告期一致。
5. 集团独立性需有该时点可用的证据 ID，且不同集团。
6. 后续观察覆盖要同等完整，不能只认真检索结果案例。

匹配过程不读取未来结果来挑公司。缺特征、集团依据或完整覆盖即排除，逐企业记录原因。结果保存候选数、输入特征、快照版本、距离、方法版本与确定性 ID；相同输入及资料状态重跑得到相同 ID。

本轮实际导出 `data/exports/comparisons.json`：广东紫晶 2023-04-23、希荻微 2026-10-02，各检查另外 19 家主体，**合格对照均为 0**。有 10 家 comparison_pool 候选并不等于有 10 家“未出事”公司。原因包括行业不同、时点特征缺失、现金流条件不符、集团独立性和观察覆盖未完成。

当前实现是保守的同业现金流候选筛查，不是同冲击因果研究。未实现价格行情、复权、冷却期、倾向评分、逻辑回归或概率模型；没有可报告的预测准确率、PR-AUC 或违约概率。未找到对照时照实展示不足，不先看结果再硬配。
