仅巨潮来源实际完成采集链路。未依赖 AKShare、Tushare、付费接口或 LLM 密钥；不声称复现其数据能力。公开目录有 6,259 条证券记录的本次响应，包含历史简称/退市主体，**不等于 6,259 家已核验企业**。

适配器 `services/acquisition.py` 只接受巨潮允许域名的 HTTPS、公网目标，拒绝带凭据 URL、额外端口和未许可重定向，流式限制 20 MiB，并检查 PDF 魔数。默认串行、请求间隔 0.35 秒，网络类失败最多 3 次；401/403/451 停止。下载时按 SHA 保留版本，续跑重新检查缓存 hash。遇验证码/登录/收费不绕过。

站点可访问与允许商业批量抓取/再分发是不同问题。本轮没有获得批量再分发授权，新增 235 份原文、提取全文和本机数据库均不推送 GitHub；只提交官方 URL、版本 hash、必要短摘录、配置、质量记录和代码。已有两份演示 PDF 保留原仓库状态，不额外扩大其授权声明。公开部署、商用和大规模更新前需由项目方确认来源使用条款与许可。

无网络权限时可用本地 `import-pdf`（见 runbook）导入有权使用的文件；只记为 candidate 且历史版本不确定，不能自动获得支持或回测资格。网页“任意企业”输入实际查询巨潮目录/索引；未覆盖非上市企业提供公开检索链接，尚无通用网页搜索 API 或自动身份消歧，不承诺任何名字都有核验结论。

原文内的命令、广告和模型指令均当数据。提取只读取文字；不会执行附件脚本。日志不记录 API 密钥，凭据不进入 manifest。
