## 时间和选择偏差

配置检索起点 2018-01-01，本轮实际文档公开范围 **2019-08-31—2026-09-30**。最后获取 `2026-10-02T01:15:25.520001+00:00`，最后 agent 表格复核 `2026-10-02T01:55:20.046280+00:00`。获取晚于历史事件，所以是历史重建，不是当年实盘预警。

历史案例是围绕已知结果选样，失败比例没有市场解释。`comparison_pool/current_focus` 是配置候选队列，尚未完成前瞻登记、同强度持续观察和成熟窗口；**不能称为已建成前向评估数据集**。right_censored / insufficient_coverage 按指定企业、日期、窗口动态计算，库内 6 条持久化正向记录不是 20 家固定窗口的分类成绩。

没有预测训练、外部用户验证、因果识别或全市场覆盖率。文献仅为方法参考，没有复制缺许可代码或宣称复现论文结果。

## 许可和复现边界

新增原文及全文未随仓库分发，先按 `INGEST_RUNBOOK.md` 获取并校验。官方可访问不等于有商业再分发授权；仓库未新增代码许可证，也不代表替现有作者授予授权。查询站点 HTTP 状态见 SOURCE_POLICY；北交所/工商等受限，没有绕过。所有机密、密钥、数据库、日志、虚拟环境、构建产物均不在提交中。

尚未达到：200 条支持断言、合格同冲击/同业对照、完整别名与母子/担保有效期、全平台转载/修订关系、OCR 集成、自由生成但逐句受约束的模型摘要、通用联网搜索 API、生产部署/账户系统。原因是原文表格和事件阶段必须逐条核对、观察覆盖未成熟、部分来源需权限；不能用抓取量或模板填满这些目标。
