# 历史时点与防泄漏

业务日期按中国标准时间 UTC+8，获取/复核时间保存带时区 ISO-8601。巨潮索引仅精确到公开日，因此 `available_at=published_at+1日`，查询 `as_of=T` 表示 T 零时可用集合，不作同日先后推断。

- occurred_at：原文描述的发生日；不确定用 null。
- published_at：本库指定版本的公开日期；不承诺已找到全网最早时间。
- available_at：按日期精度保守推得的可用日。
- effective_at：原文明示的决定生效日。
- fetched_at / reviewed_at：本系统获取和 agent 核对的真实时间。
- period_end：财务期间末日；不能替代公开日。
- supersedes_id：替代版本关联；替代只在新版本可用后影响视图。当前没有独立 superseded_at 列。

`snapshot` 的 SQL 先限制文档可用日期，再限定支持状态；未来文档不进入响应。`outcomes` 另查 (T, T+窗口]，前端必须点击才请求。全文检索也先限制日期。未确认版本时间的变更原文标 `historical_availability_uncertain`，排除严格回放；不确定替代也不能抹掉旧的已确认版本。

财务核验从该文档版本的当期列取数，后续重述不能修改旧文档。主体名称取该时点断言中的发行人名，未核对则只显示证券代码；选择列表是当前身份索引，明确不代表完整历史简称。研究行业标签是抽样分类，不是已验证的时点行业指标。

2026 年获取早年公告用于“按公开时间重建的历史回放”，不等于系统当年预警。历史模式不调用自由生成模型，也不把结果写入现金延付参数。前端缓存文档以版本 ID、查询以企业+日期隔离；旧来源缓存升级命名空间。

限制：尚未做全网首次披露核查、完整历史证券代码/名称有效期和所有更正链；因此不能将当前资料库称为严格交易回测数据集。结果型案例、当前队列和页面全库统计不得混算预测指标。
